# WeChat 聊天截图生成器

程序化生成微信风格聊天截图，文字 100% 精准，无需 AI 生成。

## 功能

- 头像上传 + 用户 ID
- 多条消息对话流
- 接收/发送两种气泡颜色
- 时间标签、撤回消息、引用回复
- 实时 Canvas 预览
- 导出 PNG / 复制到剪贴板
- 响应式布局（手机/平板/桌面）

## 技术栈

React + TypeScript + Tailwind CSS + Canvas API + Vite

## 使用

```bash
npm install
npm run dev        # 开发
npm run build      # 构建
```

打开 `dist/index.html` 或访问开发服务器即可使用。
